# Workout-Schedule-Calc

**Workout-Schedule-Calc** – це Python програма, яка допомагає визначати дні для тренувань на основі вашого графіка. Програма враховує робочі дні, дні відпочинку та дозволяє планувати тренування з урахуванням дня, який ви обрали для початку планування.

## Опис

Програма генерує список днів для тренувань у певному місяці. Алгоритм визначає, чи є конкретний день вільним для тренувань, робочим або днем відпочинку, залежно від того, який день ви вибрали для планування.

## Використання

1. Програма приймає на вхід:
   - Рік, місяць і день, з якого планується початок графіка тренувань.
   
2. Програма визначає дні тренувань відповідно до правила, що тренування повинні відбуватись кожні два дні на тиждень.

3. Результатом є список днів, які вказують на те, коли у вас буде тренування, робота або день відпочинку.

## Вимоги

- Python 3.x
- Модулі:
  - `datetime`
  - `calendar`

## Як запустити
В терміналі вашого IDE зробіть наступне:
1. Склонуйте репозиторій:
   ```git clone https://github.com/yourusername/Workout-Schedule-Calc.git```
2. Перейдіть у директорію проєкту:
  ```cd Workout-Schedule-Calc```
3. Запустіть програму:
  ```python workout_schedule_calc.py```
